Email Spam Classifying Models

Authors: Luke U and Jack B

We have trained two different models that allow for classifying. One is a Gaussian Naive-Bayes model and the other is a Random Forest classifier. They do not run at the same time. 

Libraries to have installed:
1. pandas
2. numpy
3. matplotlib
4. sklearn

To run the models from root folder:

Classification-Tree

    python ./models/classification-trees/tree.py

Gaussian Naive-Bayes

    python ./models/gaussian-naive-bayes/GNB.oy

Within these files are commented out lines that generated graphs for the different models on their initial versions. Those can be found under the reports/figures folder.
